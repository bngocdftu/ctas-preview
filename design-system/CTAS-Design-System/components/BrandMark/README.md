# BrandMark
The CTAS typographic mark: a brand-red square with a white C, then the name in bold sans.

- Use it at the left of the nav bar and in compact headers. It links home (`href`, default `#`).
- `parent` (default "Đại học Ngoại thương") is the small uppercase line above the name; `showParent={false}` hides it, as the site does on phones.
- `name` defaults to "CTAS". Do not replace the square with an image or change its colour from `brand`.
- Next to it on desktop the site places the FTU seal (`assets/Logos/ftu-seal.png`) and a thin divider; that seal is FTU's mark, not part of this component.
